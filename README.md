# Larry Deville — Portfolio Website

A responsive personal portfolio for `larrydevillelawrence.github.io`.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and current year
- `larry-deville.png` — portrait supplied by Larry

## Publish with GitHub Pages (no Git commands required)
1. Open your repository: `larrydevillelawrence.github.io`.
2. Choose **Add file → Upload files**.
3. Upload the four files in this folder directly into the repository root.
4. Commit the changes.
5. Go to **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then **Save**.

The portrait must be uploaded beside `index.html` with the exact filename `larry-deville.png`.

## Before publishing
Review every project description and update it to reflect what is actually implemented. The GetWell Pharmacy Management System is described as a project in development, and the school pocket-money system is labelled as a concept. Add live demo and source-code links only when those links exist.

Google Fonts require an internet connection; the site has system-font fallbacks.
