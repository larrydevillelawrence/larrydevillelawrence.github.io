# Larry Deville Portfolio Website

A responsive futuristic portfolio made with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content
- `style.css` — layout, theme, and responsive design
- `script.js` — mobile navigation and footer year

## Publish with GitHub Pages
1. Create a repository named `larrydevillelawrence.github.io` under your GitHub account.
2. Upload these files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. After deployment, visit `https://larrydevillelawrence.github.io`.

## Before sharing
- Add a professional email address if you want to publish one.
- Verify project descriptions and statuses.
- Add links only to real repositories or demos.
- Test on mobile and desktop.

Google Fonts is loaded from an external service. The page itself uses static files and does not require a build step.
